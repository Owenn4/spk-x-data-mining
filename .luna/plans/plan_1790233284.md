## Goal & Overview
Build the SPK x Data Mining platform for IDX (Indonesia Stock Exchange) stock analysis. This integrates:
1. Data Ingestion & Feature Engineering (yfinance) for LQ45/IDX tickers computing multi-year metrics, YoY growth, ROE, PER, PBV, etc.
2. Data Mining & Unsupervised Clustering Engine (K-Means, PCA 2D/3D projection, Elbow & Silhouette metrics, automatic cluster labeling).
3. SPK TOPSIS Ranking Engine (vector normalization, weighted normalized matrix, positive/negative ideal solutions, euclidean distances, and relative closeness score Vi).
4. FastAPI backend service exposing REST endpoints for stock data ingestion, clustering, PCA visualization coordinates, and dynamic TOPSIS re-weighting calculations.
5. Modern interactive dashboard UI with cluster scatter plots, financial radar charts, dynamic TOPSIS weight sliders, and transparent step-by-step decision matrices.
